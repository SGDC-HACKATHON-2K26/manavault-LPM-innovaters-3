## 🚀 About ManaVault

**ManaVault** is a personal digital workspace designed to bring everyday information and creative content together in one organized place.

From class notes and important records to photos, documents, drawings, and reminders, ManaVault aims to make saving, finding, and managing personal information easier through a unified interface.

Developed by **Team LPM Innovators** for **SGDC HACKATHON 2K26**, ManaVault explores the idea of a personal vault that can evolve from local storage into a secure, connected, and intelligent digital workspace.

## 🎯 The Problem

People often keep their notes, documents, photos, ideas, and reminders scattered across different applications and folders. This can make information difficult to find, organize, and maintain.

ManaVault aims to address this fragmentation by bringing different types of personal content into a single, convenient workspace.

## 💡 Our Solution

ManaVault provides a unified interface for creating, storing, and organizing personal content, with a roadmap toward secure cloud services and intelligent assistance.

## ✨ Key Features

### 🏠 Home Dashboard
View your digital workspace and get a quick overview of saved content.

### ✍️ Notes & Records
Create and organize class notes, ideas, lists, personal records, and important text.

### 📁 Files & Media
Keep documents, images, screenshots, PDFs, videos, and other supported files organized.

### 📷 Capture & Voice
A dedicated space for capture and voice-related workflows as supported by the implementation.

### 🎨 Drawing Studio
Create drawings using a mouse or touchscreen and save your artwork.

### 🧠 Smart Organizer
Suggest folders based on keywords in notes using simple local rules. A connected AI model is not yet integrated.

### ⏰ Reminders
A dedicated area for managing reminders and keeping track of important tasks.

### ♻️ Recycle Bin
Provide a separate space for managing deleted content, subject to the current implementation.

### ⚙️ Personalization
Customize the workspace to suit individual preferences.

## 🔐 Privacy, Storage & Connectivity

ManaVault currently includes a local-first experience. The following distinctions are important:

| Capability | Status |
|---|---|
| Local workspace and content management | Available as implemented |
| Keyword-based organization | Simple local rules |
| User sign-in | Backend integration required |
| Automatic cloud backup | Not connected yet |
| Secure multi-device synchronization | Not connected yet |
| Connected AI service | Not connected yet |

**Important:** Local browser storage is not a substitute for a verified backup. Users should export backups regularly where supported and avoid storing sensitive information on shared or untrusted devices.

ManaVault does not require users to enter their Gmail passwords into the application. Any future Google sign-in should use a proper OAuth-based authentication flow.
